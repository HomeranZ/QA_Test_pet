# Баг-репорты — SauceDemo

## BUG-01: Некорректная сортировка по цене (High to Low)

**Severity:** Major
**Priority:** High
**Environment:** Chrome 120, macOS

**Предусловие:** Пользователь авторизован, открыт каталог.

**Шаги воспроизведения:**
1. Выбрать сортировку «Price (high to low)».
2. Проверить порядок цен.

**Ожидаемый результат:** Товары отсортированы по убыванию цены (сначала самые дорогие).

**Фактический результат:** Товары отсортированы некорректно (цены идут не по порядку).

## BUG-02: Кнопка «Continue Shopping» не работает

**Severity:** Minor
**Priority:** Medium
**Environment:** Chrome 120, macOS

**Предусловие:** В корзине есть товар.

**Шаги:**
1. Открыть корзину.
2. Нажать «Continue Shopping».

**Ожидаемый результат:** Переход на страницу каталога.

**Фактический результат:** Кнопка не реагирует.

---

## BUG-03: Сообщение об ошибке не исчезает после ввода

**Severity:** Trivial
**Priority:** Low
**Environment:** Chrome 120, macOS

**Шаги:**
1. Ввести невалидные данные на странице логина.
2. Нажать Login.
3. Начать вводить валидные данные.

**Ожидаемый результат:** Сообщение об ошибке исчезает.

**Фактический результат:** Сообщение остаётся до повторной отправки формы.
