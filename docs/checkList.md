# Чек-лист — SauceDemo

## Авторизация
- [ ] Вход с валидными данными (`standard_user` / `secret_sauce`).
- [ ] Вход с невалидным паролем.
- [ ] Вход с пустыми полями.
- [ ] Вход заблокированным пользователем (`locked_out_user`).
- [ ] Проверка сообщений об ошибках.

## Каталог
- [ ] Отображение всех 6 товаров.
- [ ] Сортировка по имени (A-Z, Z-A).
- [ ] Сортировка по цене (low-high, high-low).
- [ ] Кнопка «Add to cart» меняется на «Remove».

## Корзина
- [ ] Добавление товара → счётчик увеличивается.
- [ ] Удаление товара → счётчик уменьшается.
- [ ] Переход в корзину через иконку.
- [ ] Отображение добавленных товаров.

## Checkout
- [ ] Ввод имени, фамилии, индекса.
- [ ] Проверка обязательных полей (пустые).
- [ ] Завершение заказа.
- [ ] Отображение итоговой суммы.
