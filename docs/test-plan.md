# Test Plan — SauceDemo

## 1. Введение
Тест-план описывает процесс ручного тестирования веб-приложения SauceDemo (интернет-магазин).

## 2. Объект тестирования
**URL:** https://www.saucedemo.com/

Функционал:
- Авторизация
- Каталог товаров
- Корзина
- Оформление заказа (checkout)

## 3. Scope

### В scope (тестируем):
- Функциональность авторизации (валидные/невалидные данные).
- Отображение и сортировка товаров.
- Добавление/удаление товаров в корзину.
- Процесс оформления заказа.

### Out of scope (НЕ тестируем):
- Нагрузочное тестирование.
- Тестирование безопасности (SQL-инъекции, XSS).
- Мобильная версия (только desktop).
- Доступность (a11y).

## 4. Стратегия тестирования
- **Ручное функциональное тестирование.**
- **Тест-дизайн:** классы эквивалентности (КЭ), граничные значения (ГЗ).
- **Исследовательское тестирование** (exploratory).

## 5. Окружение
- OS: macOS 14+
- Браузер: Chrome 120+
- Разрешение: 1920x1080

## 6. Тестовые данные
- **Валидный пользователь:** `standard_user` / `secret_sauce`
- **Невалидный пароль:** `wrong_password`
- **Заблокированный пользователь:** `locked_out_user` / `secret_sauce`

## 7. Критерии начала (Entry Criteria)
- Приложение доступно по URL.
- Тестовые данные готовы.

## 8. Критерии завершения (Exit Criteria)
- Все тест-кейсы выполнены.
- Все найденные баги оформлены.
- Отчёт отправлен.

## 9. Риски
- Нестабильный интернет → пропущенные проверки.
- Тренажер может измениться без предупреждения.

## 10. Расписание
- День 1: Авторизация + каталог.
- День 2: Корзина + checkout.
- День 3: Оформление баг-репортов.
